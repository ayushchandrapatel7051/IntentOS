# SOUL.md — OpenClaw Behaviour Rules
# ==========================================
# This file defines your personal macros and rules.
# The agent reads this on startup and uses it to customize behavior.
# Edit this file in plain English to teach OpenClaw your preferences.

## Macros

### start my day
- Open Gmail in Chrome
- Check Google Calendar for today's events
- Open VS Code with the last active project
- Send "Good morning" to my team Telegram group

### end my day
- Save all open work
- Send today's summary to my Telegram
- Close non-essential applications

### prepare for meeting
- Open the meeting link from calendar
- Take notes document ready
- Mute notifications

### clean downloads
- Group files in Downloads by type (documents, images, videos, archives, code)
- Rename files with date prefix
- Delete files older than 30 days (with confirmation)
- Remove duplicate files

## Rules

### Safety
- Always ask before deleting files permanently
- Never run `rm -rf /` or any dangerous recursive delete
- Do not run any `git push` without my explicit confirmation
- Do not send messages to unknown contacts without confirmation

### Preferences
- Prefer WhatsApp over Telegram for personal contacts
- Prefer Telegram for work-related messages
- Use dark mode in all applications when possible
- Save screenshots to ~/Screenshots with timestamp names

### Communication Style
- Keep automated messages concise and professional
- Add emoji sparingly — only when contextually appropriate  
- Always include a greeting when messaging someone for the first time today

### File Organization
- Documents go to ~/Documents/organized/
- Code projects stay in their original locations
- Downloaded PDFs should be renamed with their title
